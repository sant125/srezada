# The Site Reliability Workbook, destrinchado

Notas de estudo do [Google SRE Workbook](https://sre.google/workbook/table-of-contents/), capítulo a capítulo. Não é resumo: é o livro reexplicado até eu entender de verdade, com analogia antes de fórmula e jargão só depois da ideia.

## Formato de cada capítulo

- A ideia central primeiro, o nome técnico depois
- Analogias e exemplos numéricos antes de definição formal
- Conexão com meu stack (Kubernetes, Prometheus, Go, AWS/GCP)
- O que isso vira em entrevista
